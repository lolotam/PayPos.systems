# Row 16d-3 — same hours for all days

Implements Abu Salem's binding DH-Q2 pick, approved by Waleed on 2026-10-11:
one range with days off, «مع امكانية التغيير».

Each editable branch form opens “Same hours for all days”. Enter a start/end and optional
break, or select a currently filled weekday. Initially, weekdays missing from the current
form are checked as days off; uncheck them to include them. Apply replaces the form's
working days with independent copies and clears every checked day off. Each day remains
editable. Only the existing Save submits these changes, using the unchanged contract
and server validation (maximum 16 h, break strictly inside, overnight and 12 h supported).

UI reference lock: retain the existing staff form's spacing and `packages/ui` tokens.
The shadcn Refero style informs the bordered, compact panel; Cal.com's availability
copy-times screen informs source selection, day checkboxes and a separate Apply action.
The bundled Refero form craft guidance supplies clickable labels and focus behavior.
Muted supporting text explains that applying and saving are separate actions.

No API, database, permission, contract, or library changes.
